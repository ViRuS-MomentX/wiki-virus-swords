# Кодекс McSwords

Вики плагина McSwords для Paper 1.21.11: клинки, материалы, святилища, рост клинка,
родословные и достижения.

Сайт — один самодостаточный файл `index.html`: приложение на Vue 3, собранное Vite
в одну страницу (скрипты, стили и картинки встроены). Открывается через GitHub Pages:
**Settings → Pages → Deploy from a branch → `main` / `(root)`**.

Модели оружия — ресурспак Fantasy Weapons (автор nongkos).
